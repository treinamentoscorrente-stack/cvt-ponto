CVT CONTROLE DE PONTO — PUBLICAÇÃO NA VERCEL

Este pacote está preparado para Next.js + PostgreSQL (Neon).

IMPORTANTE
- Não há senhas ou DATABASE_URL dentro deste pacote.
- O banco Neon da CVT já possui o schema de produção.
- As Vercel Functions estão configuradas para São Paulo (gru1), próximo ao banco Neon.

PUBLICAÇÃO
1. Acesse https://vercel.com/drop
2. Arraste a PASTA cvt-ponto-definitivo (descompactada), não apenas este arquivo de instruções.
3. Nome sugerido do projeto: cvt-ponto
4. Antes de usar a aplicação, configure no projeto Vercel:
   DATABASE_URL = conexão pooled do Neon
   ADMIN_LOGIN = CVT
   ADMIN_PASSWORD = senha inicial escolhida para o administrador
5. Faça o primeiro deploy.
6. Execute o seed do administrador por ambiente seguro/local conforme README.
7. Teste /api/health, login administrativo, cadastro de funcionário e uma jornada completa.

Não publique ADMIN_PASSWORD no código-fonte.
